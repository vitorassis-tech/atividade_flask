Sobre o projeto

Este projeto foi desenvolvido como atividade prática utilizando Python, Flask e SQLite.

Objetivo

O objetivo deste projeto é aplicar os conhecimentos adquiridos durante as aulas, desenvolvendo uma aplicação web capaz de cadastrar, visualizar, editar e excluir conteúdos.

Tecnologias utilizadas

  • Python
  • Flask
  • SQLite
  • HTML
  • CSS
  • JavaScript
  • Jinja

Funcionalidades

  • Listagem de conteúdos cadastrados
  • Visualização individual de conteúdos
  • Cadastro de novos conteúdos
  • Edição de conteúdos
  • Exclusão lógica de conteúdos

Sobre a atividade

A aplicação utiliza o framework Flask para gerenciar as rotas e páginas do sistema e o SQLite para armazenar os conteúdos cadastrados.

As páginas HTML utilizam templates com Jinja, permitindo a integração entre os dados processados pelo Python e o conteúdo exibido no navegador.
