Sobre a aplicação

Este projeto foi desenvolvido como uma atividade prática de desenvolvimento web utilizando Python e Flask.

A aplicação permite cadastrar, visualizar, editar e excluir conteúdos através de uma interface integrada a um banco de dados SQLite.

Tecnologias utilizadas

Python: linguagem utilizada no desenvolvimento da aplicação.

Flask: framework utilizado para criação das rotas e páginas web.

SQLite: banco de dados utilizado para armazenar os conteúdos.

HTML e CSS: utilizados para estruturar e estilizar as páginas.

JavaScript: utilizado para complementar as funcionalidades da interface.

Funcionalidades

O sistema possui operações de cadastro, consulta, edição e exclusão lógica de conteúdos.
